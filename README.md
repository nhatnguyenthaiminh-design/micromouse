# Micromouse Simulator

## 1. Project Overview

2D Micromouse robot simulation software.

## 2. Technologies

- C++17
- CMake
- Git

## 3. Project Structure

- include/
- src/
- docs/
- tests/

## 4. Build Instructions

```
cmake -S . -B build
cmake --build build
```

## 5. Run Application

Run the generated executable.

- Windows (MSVC): `.\build\Debug\MicromouseSimulator.exe`
- Linux / MinGW / Ninja: `./build/MicromouseSimulator`
